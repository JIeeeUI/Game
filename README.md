# 🌾 농장 지키기 (두더지 잡기)

브라우저에서 실행되는 두더지 잡기 클리커 게임입니다.

## 게임 규칙

- 🎯 **성공 조건**: 두더지 20마리 잡기
- ❌ **실패 조건**: 두더지 5마리 놓치기
- 🖱️ **조작**: 두더지가 나타난 구멍을 클릭
- ⏱️ 두더지는 2초 뒤 자동으로 도망갑니다
- ⚡ **속도 UP**: 두더지를 잡을 때마다 두더지 등장 속도가 빨라집니다.

## 점수 규칙

- 두더지 1마리 = **1점**
- **5마리 연속** 잡으면 콤보 시작 → 그때부터 **1점 추가** (2점)
- 놓치면 콤보 리셋

## 저장되는 정보

- 최고 점수 (브라우저 localStorage)
- 음소거 설정

현재 판의 점수·피해·콤보는 새 게임마다 초기화됩니다.

## 사용 기술

- HTML / CSS / JavaScript (프레임워크 없음)
- Web Audio API (효과음 직접 생성)
- localStorage (기록 저장)
