# Dot Game (Dot Connect)

브라우저에서 실행되는 드래그 기반 퍼즐 게임입니다.

## 게임 규칙

* 🎯 **목표:** 제한된 이동 횟수(30회) 안에 최대한 많은 점을 지워 점수를 획득하세요.
* 🖱️ **조작:** 마우스(또는 터치)를 누른 채로 같은 색 점을 드래그하여 연결합니다.
* 🔗 **연결:** 상하좌우로만 이동 가능하며, 3개 이상 연결하면 점이 사라집니다.
* ↩️ **취소:** 드래그 중 실수했다면 왔던 길로 되돌아가서 경로를 취소할 수 있습니다.
* 🔀 **재배치:** 보드에 연결할 수 있는 점이 하나도 없으면 자동으로 판이 섞입니다.
* ⚠️ **어려움 모드:** 7x7 크기로 판이 넓어지며, 2초마다 무작위로 점이 사라집니다.

## 점수 규칙

* 기본 점수: 1점
* 3개 이상 연결한 개수만큼 점수 추가 (예: 3개 연결 = 1점)
* 5개 이상 연결 시 화면에 보너스 효과가 나타납니다.

## 저장되는 정보

* 최고 점수 (브라우저 localStorage)
* 음소거 설정

현재 판의 점수, 이동 횟수, 보드 상태 등은 새 게임마다 초기화됩니다.

## 사용 기술

* HTML / CSS / JavaScript (프레임워크 없음)
* Web Audio API (효과음 직접 생성)
* localStorage (기록 저장)
* SVG (드래그 연결선 렌더링)
